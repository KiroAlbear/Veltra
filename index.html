Veltra

The Clinic Operating System

Veltra is a Next.js, TypeScript, Tailwind, and Zustand demo for clinic workflows: daily briefs, patients, appointments, specialty data, messages, billing, labs, and audit trails.

This repository is an application source tree. To run it locally, install dependencies, copy .env.example to .env, then start the Next.js dev server.
